# WearTo

Multi-module Android and Wear OS application designed to add items to Todoist with minimal effort.

## Build & Environment

- **Build tool:** Gradle (`./gradlew`)
- **Verify:** `./gradlew check`
- **Assemble:** `./gradlew assembleDebug`
